# Android TTSとの話速同期（Issue #7）

## 仕様

- 「音声合成（VOICEVOX）」の「Android TTSの話速に合わせる」は既定オフ。
- 補正は0.5〜2.0倍の連続スライダーで調整。中央が1.0倍。正規化位置pに対し `2^((2p-1)^3)` とし、中央付近の変化を小さくする。保存済み倍率から逆変換して位置を復元する。「遅く／速く」の表示と1.0へ戻すボタンを備える。0.5・0.8・1.0・1.25・2.0の目盛は倍率から逆算した位置に配置する。
- オフ: 保存済みの手動速度。オン: Android共通話速 × 同期専用の補正倍率（既定1.0）。手動速度は上書きしない。
- `Settings.Secure.TTS_DEFAULT_RATE` を毎回の合成開始時に読む。100が等速。Androidの設定画面から戻ると表示も更新する。
- Android全体の設定への書き込みはない。端末TTSは従来どおりAndroidの既定話速を使う。
- 未設定・非正のAndroid話速、読み取り拒否は1.0にフォールバック。速度・補正の非正値や非有限値も1.0として扱う。
- 話者・実効速度・音量を合成開始時に固定し、キャッシュと全サーバーへの合成要求で共有する。
- 話速変更は次の合成から反映。すでに合成済みの音声は作り直さない。
- エンジン固有の非公開設定は取得できない。同じ倍率でも声や文章で速度感が違うため、補正倍率を調整できる。
- 記事ごとの意図的な話者交代モード（#6）は別機能。現在のVOICEVOXと端末TTSフォールバックの共通合成経路へ適用。

- 実エンジンで同じ文を合成・再生。Android話速0.73、VOICEVOX話者2（四国めたん）、補正1.0。ゆっくり10.9139375秒、四国めたん11.04秒、長さの差は約1.2%。この文章では補正なしで近い。合成WAVを端末から取得してフレーム数÷サンプルレートで測定。
- 比較文: 「今日は読み上げ速度を確認します。同じ文章を二つの声で読み上げます。ニュースを聞くときの速さを比べてください。」
- ユーザー聴感: ゆっくりはちょうどよいが、同じ速さのめたんはだるく感じるとの回答。数値入力欄を補正スライダーへ変更し、端末TTSを変えずにVOICEVOXを速められるようにした。
- 初版UIでは同期オンで手動速度欄が無効になり「Android: 0.73倍 → VOICEVOX: 0.73倍」、オフで手動1.0の編集が復帰することを実機UI階層で確認。線形スライダー版で左右の保存値とリセット、同期オフへの復帰を確認済み。ユーザー要望により中央の感度を下げた非線形カーブと目盛に変更。最終版でも目盛表示、左側の補正0.84305775、右側の補正1.1841351と保存値の一致を確認。1.0へのリセット、同期オフで手動速度が編集可能に戻ることも確認。スクリーンショットでつまみと中央1.0の整列、目盛の非等間隔配置、ラベルに重なりがないことを確認。検証後は同期オフ・補正1.0へ復元。

## 根拠

ローカルSDKの `android/speech/tts/TextToSpeechService.java` は `getDefaultSpeechRate()` でSecure設定を読み、リクエストに速度指定がなければこの値を使用する。`Speaker` は速度を指定しないため、この既定値が端末TTSにも適用される。
