# Mimiyori 利用マニュアル

## 通知を読み上げる

Mimiyoriの通知アクセスを許可し、読み上げを有効にして、「通知」設定で対象アプリを選ぶ。MimiyoriはAndroidに届いた通知の内容を読むため、相手ごとの通知は元のアプリで設定する。

## LINEの通知とメンション

読みたいトークだけを読み上げるには、LINE側で次のように設定する。

1. 読みたい相手・グループのトークは通知オンにする。
2. 読みたくない相手・グループのトークは通知オフにする。
3. LINEの **ホーム → 設定（歯車）→ 通知 → 自分へのメンション通知** をオフにする。

「自分へのメンション通知」がオンだと、トークを通知オフにしていても、個人宛てや全員宛て（`@All`）のメンションで通知が届く場合がある。その通知もMimiyoriの読み上げ対象になる。

この設定をオフにすると、通知オフのトークからメンションで通知されるのを防げる。通知オンのトークの通知は引き続き届く。LINE全体やAndroid側のLINE通知をオフにすると、読みたいトークの通知も届かなくなるので、変更するのは「自分へのメンション通知」。この設定はトークごとではなく共通で適用される。

MimiyoriからLINEのトーク別通知設定は参照できない。通知オンの相手のメンションまで除外しないよう、Mimiyoriにはメンションの一律除外機能を設けていない。

LINEの「メッセージ通知の内容表示」もオンにする。本文が通知に含まれなければ、Mimiyoriでは本文を読めない。

手順は2026年10月確認。LINEの更新で画面の名称や配置が変わる場合は、[LINE公式ヘルプ「通知の基本的な設定」](https://help.line.me/line/smartphone?contentId=20011380&lang=ja)を参照。

## イヤホンで読み上げを止める

読み上げ中やチャイム再生中に、イヤホンの再生／一時停止・曲送り・曲戻しボタンを操作すると、現在の再生と待機中の音声を中止する。一時停止・続きからの再開には対応しない。新しく届く通知は通常どおり読む。

WF-C700Nの標準設定は右ボタン1回。ボタン割り当てを変更している場合は「再生／一時停止」の操作を使う。LE302は左長押しで「次の曲」、右長押しで「前の曲」が送られることを実機ログで確認済み。読み上げ中は左右どちらも中止として扱うよう対応した（対応後の実機再確認待ち）。この操作で音楽の曲送り・曲戻しは行わない。

Mimiyoriは再生開始後だけボタンを受け付け、終了・中止で受付を解除する。初回の音声合成待ちは対象外。音楽との同時再生では操作先が音楽アプリになる場合もある。Androidの模擬操作では中止を確認済みだが、実際のイヤホンと音楽アプリ併用時の動作は未確認。

### Lenovo LE302の操作表

ユーザー提供の操作説明に基づく。左・右の長押しで送られる操作は端末ログとも一致した。

| 状態 | 操作 | イヤホンの機能 |
| --- | --- | --- |
| 音楽再生 | 左右どちらかを2回タップ | 再生／一時停止 |
| 音楽再生 | 右を3秒長押し | 前の曲 |
| 音楽再生 | 左を3秒長押し | 次の曲 |
| 音楽再生 | 左右どちらかを3回タップ | 音声アシスタント |
| 着信中 | 左右どちらかを2回タップ | 応答 |
| 着信中 | 3秒長押し | 着信拒否 |
| 通話中 | 左右どちらかを2回タップ | 終話 |
| ペアリング情報リセット | 5回連続タップ | ペアリング情報をリセット |

Mimiyoriの再生中は、2回タップ・左3秒長押し・右3秒長押しを読み上げ中止として扱う。音声アシスタント・通話・ペアリングの操作はMimiyoriでは変更しない。修正版での実機操作は確認待ち。
